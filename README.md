#  E-commerce Customer Analytics

##  Project Overview

This project analyzes e-commerce sales and customer data using Python, PostgreSQL, SQL, and Power BI.
The goal is to identify sales trends, profitable categories, customer segments, and regional performance to support business decision-making.

## Tools Used

* Python
* Pandas
* PostgreSQL
* SQL
* Power BI
* Git & GitHub

## Key Business Questions

* Which category generates the highest sales?
* Which region generates the highest profit?
* Which customer segment contributes the most sales?
* How do sales change over time?
* Which areas have high sales but low profitability?

##  Dashboard

The Power BI dashboard provides an interactive view of sales, profit, orders, customers, categories, regions, and segments.

## Conclusion

This project demonstrates an end-to-end data analytics workflow using Python for data preparation, PostgreSQL for data storage, SQL for analysis, and Power BI for visualization.
